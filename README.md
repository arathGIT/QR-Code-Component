# Frontend Mentor - QR Code Component

This is a solution to the QR Code Component challenge from [Frontend Mentor](https://www.frontendmentor.io). The challenge requires building a responsive card with a QR code, heading, paragraph, and attribution footer, following the provided design specifications.

## Layout

The designs were created for the following widths:
- Mobile: 375px
- Desktop: 1440px

The implementation is fully responsive and adapts to all screen sizes starting from 320px.

## Colors

The project uses the following color palette:
- White: hsl(0, 0%, 100%)
- Slate 300: hsl(212, 45%, 89%)
- Slate 500: hsl(216, 15%, 48%)
- Slate 900: hsl(218, 44%, 22%)

## Typography

- Font family: [Outfit](https://fonts.google.com/specimen/Outfit)
- Weights: 400, 700
- Paragraph font size: 15px

## Technologies Used

- HTML5 for semantic structure
- CSS3 with Flexbox and Media Queries for responsive design
